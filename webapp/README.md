# Chimichan MVP Web App

This is the MVP (Minimum Viable Product) for the Chimichan project. It provides a simple interface for:

1. Inputting Japanese text.
2. Viewing decorated output with annotations.
3. Inspecting intermediate parsing results.

## How to Run

1. Open `index.html` in any modern web browser.
2. Enter Japanese text in the input box.
3. View the decorated output and intermediate parsing results in their respective sections.

## File Structure

- `index.html`: Main HTML file.
- `app.js`: JavaScript logic for parsing and decorating text.
- `style.css`: Additional styles for the app.

## Future Enhancements

- Integrate with the actual parser and decorator modules.
- Add support for pitch accents and furigana.
